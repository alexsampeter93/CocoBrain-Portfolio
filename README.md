# CocoBrain

Portfolio personal de Alex bajo la marca **CocoBrain**: no es una web con
elementos 3D, es una experiencia narrativa 3D que funciona como portfolio —
*entrar en la mente de Alex*.

Construida con React, Three.js / React Three Fiber, GSAP y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev       # servidor de desarrollo
npm run build     # build de producción
npm run preview   # sirve el build para comprobarlo
```
